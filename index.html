Flash Check

WCAG 2.3.1 Tester for Chrome

Flash Check records a web page while you use it and tells you whether it fails WCAG 2.3.1, Three Flashes or Below Threshold. It checks general flashes and red flashes using the WCAG 2.2 definitions and shows where each failure happened.

Try it on the test pages

Photosensitive seizure warning. The demo page flashes rapidly, and some demos flash in saturated red. Nothing flashes until you select a Start button, and every demo stops on its own after 20 seconds.
  • Flash demos with known results
    Seven demos, each labeled with the result Flash Check should give. Start one, then run a 10 second test from the extension.
  • Engine harness
    Runs every demo through the analysis on a hidden canvas and compares the results with the expected ones. Nothing flashes on screen.
