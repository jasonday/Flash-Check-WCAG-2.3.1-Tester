Flash Check demos

Photosensitive seizure warning. These demos flash rapidly and some flash in saturated red. Do not start them if you or anyone who can see your screen may be sensitive to flashing light. Nothing flashes until you select a Start button. Each demo stops by itself after 20 seconds, and the Escape key stops all of them.

Use these to check the extension. Start one demo, then run a 10 second test from the extension button. Compare the result with the expected outcome.
